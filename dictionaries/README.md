| --- | --- | --- |
| 出行俄语 | [travel.tsv](travel.tsv) | `dengjikou` → 登机口 · выход на посадку |

打开对应文件，点 GitHub 的 **Download raw file** 下载。新版设置中打开「词库」，选择「自定义词条」，点击「导入 TSV 文件」。也可直接在「词典导入」中选择主题，再点「加入我的词条」。

预览会显示词典信息和导入结果。选择跳过、覆盖或合并重复项后，点击「确认导入」。导入后可按词典名称筛选，也可以逐条编辑。

这三份示例是旁译项目编写的词表，按仓库的 [MIT 许可证](../LICENSE)提供。制作自己的主题词典时，使用 UTF-8 TSV 格式，每行填写中文词头、触发拼音、俄语释义和可选权重，列之间用 Tab 分隔。分享第三方词表时，请保留数据来源及相应的许可证。[词典格式和贡献指南](FORMAT.md)
