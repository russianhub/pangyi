# 旁译词典文件格式

使用 UTF-8 编码的 `.tsv` 文件，兼容 UTF-8 BOM、Windows CRLF 和 LF。用实际的 Tab 分隔字段。空行和以 `#` 开头的注释可以保留。

## 元信息

把可选元信息写在第一条词条前，每项一行。旧词典可以直接从词条开始。

```text
# name: 出行俄语
# author: 旁译项目
# version: 1.0.0
# language: zh-CN -> ru
# description: 机场、车站和交通常用词
```

预览会显示这些信息。名称用作导入后默认主题。缺少名称时，本地导入使用文件名。名称最多 80 字符，作者 100 字符，版本和语言各 40 字符，说明 400 字符。

## 数据行

| 导入类型 | 列顺序 |
| --- | --- |
| 自定义词条 | 中文词头、触发拼音、可选俄语释义、可选权重 |
| 覆盖已有词的俄语 | 中文词头、拼音、俄语释义、可选备注 |

词头应含汉字，最多 32 个字符。拼音去掉声调后最多 48 个字母，输入时用 `v` 代替 `ü`。俄语最多 400 个字符，多条释义用 ` | ` 分隔。权重是 −9999 到 9999 的整数，100 起可排到内置精确首选前。完整排序规则见[用户词库](../docs/user-dictionary.md)。

导入界面会报告有问题的行，确认后写入预览中的有效修改。重复项可跳过、覆盖或合并。合并会保留原读音、优先保留原权重或备注，并追加不同的俄语义项。自定义词按词头和归一化拼音去重，释义覆盖还区分声调。导入源最多 4 MiB。每份本机词库上限是 256 KiB、5000 条数据。超过本机容量的行会列入跳过项。

## 贡献词典

以 [出行词典](travel.tsv)、[点餐词典](food.tsv) 或 [办公词典](work.tsv) 为例，在本目录添加 UTF-8 TSV，并在[词典目录](README.md)中列出下载入口和一个可试打的拼音。提交前用旁译预览，并用完整拼音检查候选。引用外部材料时，请注明来源和适用许可证。
