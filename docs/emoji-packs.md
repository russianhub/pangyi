# 表情包和符号包

旁译可以打出表情、颜文字和符号，旁边带一句短俄语。这些内容放在你自己电脑上的文本文件里。放进文件夹就生效，删掉文件就关闭。

输入法本身不下载任何东西。查词和打字都在本机完成。要从网上拿官方包时，另外运行下面的脚本。不运行脚本，输入法就不会访问网络。

## 文件放在哪

```text
%LOCALAPPDATA%\Pangyi\packs\
```

在 Windows 上，这通常是：

```text
C:\Users\你的用户名\AppData\Local\Pangyi\packs\
```

这个 `packs` 文件夹和用户词库、自定义短语在同一个「旁译」目录下面。里面每一个 `*.tsv` 都是一个包。输入法大约每秒看一次这些文件的修改时间，在你重新打一个拼音的时候生效。刚保存就立刻打，有时要再打一次。

打开这个文件夹：按 `Win + R`，输入 `%LOCALAPPDATA%\Pangyi\packs`，回车。文件夹还不存在时，用下面的脚本安装一次就会建好；你也可以自己新建。

### 启用和关闭

- **启用**：把 `某个包.tsv` 放进这个文件夹。
- **关闭**：把这个文件删掉，或者移出这个文件夹。
- 关掉其中一个，不影响别的包，也不影响用户词库。
- 输入法不会自己创建带例子的模板。文件夹空着，就等于没有包。

这和设置里的「表情模式」不是同一个开关。表情模式管的是安装包里自带的那一套表情：开了才出现，关了就没有，而且排在候选最前面。表情包不看这个开关。文件在，就按下面的排序出现。

表情、颜文字和符号都是文字，不是图片贴纸。显示成什么样，跟 Windows 的字体有关。

## 用脚本下载官方包

脚本在仓库里：`scripts/pangyi-packs.ps1`。Windows 自带的 PowerShell，以及 PowerShell 7，都可以。在仓库根目录运行。

列出官方包：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -List
```

安装其中一个（名字和 `-List` 里的第一列一样）：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Install -Name emoji-common
```

四个都装上：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Install -All
```

删掉一个：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Remove -Name emoji-common
```

按清单把已经安装的官方包都删掉。你自己另外放进去的 tsv，只要名字不在清单里，会留下：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Remove -All
```

默认从这里下载，并且核对 SHA256：

```text
https://raw.githubusercontent.com/russianhub/pangyi/main/packs/
```

清单是 `packs/index.json`，里面有名称、说明、文件名、sha256、条数和许可。下载下来的内容和清单对不上时，脚本不会把文件放进文件夹。

脚本不跟随重定向。清单里如果写了别的网址，脚本不用，只按文件名到清单所在的目录去取。

地址必须是 https。默认只允许上面这个 GitHub 仓库的 raw 地址。你要装别处的包，得自己把地址写在命令里：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Install -Name my-pack -Url https://example.com/my-pack.tsv -Sha256 这里填64位小写校验值
```

`-Url` 仍然必须是 https，不能在地址里带账号密码。校验值要对上，文件才会保存成 `my-pack.tsv`。

现在仓库里的官方包：

| 名字 | 里面是什么 |
| --- | --- |
| `emoji-common` | 常用表情。拼音关键词，常用项带短俄语 |
| `kaomoji` | 颜文字 |
| `symbols-common` | 常用标点、数学符号、货币符号 |
| `symbols-russian` | «»、破折号、№、₽，以及俄语字母 |

拼音要打全。`lubu` 出 ₽，打到 `lu` 不会出。包不参加首字母缩写，也不拿去拼更长的句子。

## 排序，以及和用户词库怎么相处

候选先按内置词库排。短语和整句始终在最前。然后才插入你的词和包里的候选。

| 权重 | 位置 |
| --- | --- |
| 不写、空着、`0`，或 `1`–`99` | 紧挨在这个拼音的**内置精确第一候选**后面。数字大的更靠前，但都不会超过那个第一名 |
| `100` 或更大 | 可以排到那个第一名的前面。越大越靠前。短语和整句仍然在更前面 |
| 负数 | 排在所有内置精确候选的后面 |

官方包都没有写权重，所以会排在内置第一名后面，不会盖住正常的词。

同一个档位里，用户词库的词排在表情包前面。你自己加的词不会被下载的包挤到后面。

包里的俄语只显示在这一条候选旁边。它不改词典里同一个词的俄语。俄语仍按这个顺序取，上面的赢：

1. `user-gloss.tsv`
2. `user-dict.tsv` 里写的俄语
3. 随软件发布的手写覆盖
4. 内置词典原来的俄语

如果包里的候选文字和当前已经有的一条词完全一样，不再另插一条，也不改那条词的俄语。

选中表情、颜文字或符号之后，不会写进自学习。这样删掉包之后，它们不会还留在候选里。包里如果写的是纯汉字，选中后仍会自学习，和用户词一样。

表情模式开着时，安装包自带的表情仍排在最前。包里如果有同一条，不再排第二次。

## 自己写一个包

用记事本新建一个 UTF-8 文件，例如 `my-pack.tsv`，放进上面的 `packs` 文件夹。列与列之间用 **TAB**，不要用空格代替。

```text
关键词	候选内容	俄语	权重
```

俄语和权重都可以空着。以 `#` 开头的整行是说明。

```text
# 我自己的符号
lubu	₽	рубль
kaixin	(≧▽≦)	радость
pozhehao	—	тире	100
```

- **关键词**写你要敲的拼音。不标声调也可以。`ü` 用 `v`。也可以写 `nǚ`，打出来是 `nv`。读音不能空。
- **候选内容**是上屏的那一串：表情、颜文字或符号。最长 64 个字符。
- **俄语**最长 400 个字符。几个义项用 ` | ` 分开。
- **权重**是 `-9999` 到 `9999` 的整数。不写就按上一节的默认位置排。

同一个关键词可以写多行，就会有多条候选。同一个关键词加上完全相同的候选写了两行，后一行生效。

建议不要用带 ZWJ 的组合表情、不要在表情后面加变体选择符、不要用旗帜和按键帽。候选窗是普通文字绘制，这些容易显示成方框。

### 分享给别人

把这个 tsv 发给对方，让对方放进他自己的 `packs` 文件夹，即可使用。

如果要放到网上给脚本安装，把文件放在一个 https 地址，自己算出 SHA256，把名字、说明、文件名、校验值、条数和许可写进一份 `index.json`。对方用 `-IndexUrl` 指向那份清单，或者用 `-Url` 和 `-Sha256` 安装单个文件。许可请在文件头用 `#` 写清楚。官方包是旁译项目自己编写的，按 CC BY-SA 4.0 分发：转给别人时保留文件头的说明，并以相同方式共享。

## 坏行和限制

读不进去的行会跳过，别的行照常用。输入法不会因为一行写错就崩溃。

警告写在：

```text
%LOCALAPPDATA%\Pangyi\packs-warnings.txt
```

没有问题时，这个文件会被删掉。最多列出 32 条具体说明，再多会再加一行「还有更多问题没有列出」。

下面这些是坏行：

- 列数不是 2 到 4 列
- 关键词是空的，或里面有空格、无法识别的符号
- 候选内容是空的，超过 64 个字符，或里面有控制字符
- 俄语超过 400 个字符
- 权重不是整数，或超出 `-9999` 到 `9999`

| 限制 | 数值 |
| --- | --- |
| 每个文件最多读 | 256 KiB（262144 字节），多出来的不读 |
| 每个文件最多收下 | 5000 行数据（注释和空行不算） |
| 最多读多少个文件 | 32 个，按文件名只取前面的 |
| 重新检查文件 | 大约每秒一次，在一次新的拼音开始时 |
| 文件名 | 以 `.tsv` 结尾。文件名中间不要再加点 |

这些上限和用户词库一样，是为了不让一个意外的大文件拖住输入法。某个文件这次正好没读成（例如你正在保存），会暂时沿用上一份，并在警告文件里记一笔。
