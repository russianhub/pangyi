# 旁译 v4.18.0｜可以加自己的词，也可以打出表情和符号

这次可以在自己的电脑上加词、改某个词的俄语，也可以把表情、颜文字和符号放进一个文件夹里，用拼音打出来。安装包里的大词典没有改。查词和打字仍然都在本机完成，输入法不会自己去上网。

**[下载 Windows 安装包：pangyi-v4.18.0.exe](https://github.com/russianhub/pangyi/releases/download/v4.18.0/pangyi-v4.18.0.exe)**

安装包未签名。若出现 SmartScreen 提示，先确认文件来自本仓库的 Release，再按文末的方法核对 SHA256。

## 自己的词和俄语

来自 [PR #10](https://github.com/russianhub/pangyi/pull/10)。安装包里的词库不能直接改。要加自己的词，或者换掉某个已有词的俄语，用记事本改这两个 UTF-8 文本文件。不用联网，也不用账号。

| 文件 | 做什么 |
| --- | --- |
| `%LOCALAPPDATA%\Pangyi\user-dict.tsv` | 添加词：词头、拼音、可选俄语、可选权重 |
| `%LOCALAPPDATA%\Pangyi\user-gloss.tsv` | 改已有词的整条俄语 |
| `%LOCALAPPDATA%\Pangyi\user-dict-warnings.txt` | 有读不进去的行时才出现 |

在 Windows 上，这个文件夹通常是 `C:\Users\你的用户名\AppData\Local\Pangyi\`。它和自定义短语、自学习是同一个地方。按 `Win + R`，输入 `%LOCALAPPDATA%\Pangyi`，回车。

第一次切换到旁译时，如果这两个 tsv 还不存在，输入法会写上带说明的模板。模板里的例子都用 `#` 注释掉了，不会突然多出候选。已经写过的文件不会被盖掉。

列与列之间用 Tab，不要用空格对齐。保存时编码选 UTF-8。改完保存，重新打这个拼音就会看一次文件。输入法大约每秒才看一次，所以刚保存就立刻打，有时要再打一次。

拼音要打全。`zhangsan` 要敲完才会出现，打到 `zhang` 不会，也不参加首字母缩写。

不写权重时，你的词排在这个拼音的内置精确第一名后面，不会盖住那个第一名。权重写成 `100` 或更大，才可以排到它前面。自定义短语和整句仍然更靠前。

同一个词、同一个读音，俄语按这个顺序取，上面的赢：

1. `user-gloss.tsv`
2. `user-dict.tsv` 里这一行写的俄语
3. 随软件发布的手写覆盖
4. 内置词典原来的俄语

这两份文件只留在你的电脑上，输入法不会上传。它们不属于词典数据的 CC BY-SA 分发。

格式、坏行会怎样跳过、多音字怎么分行，见 [用户词库](https://github.com/russianhub/pangyi/blob/main/docs/user-dictionary.md)。

## 表情包和符号包

来自 [PR #11](https://github.com/russianhub/pangyi/pull/11)。常用表情、颜文字、标点、数学符号，以及 «»、№、₽ 和俄语字母，可以做成一份「包」放在本机：

```text
%LOCALAPPDATA%\Pangyi\packs\
```

这个文件夹里每一个 `*.tsv` 都是一个包。放进去，下一次打这个拼音就生效；删掉文件，就关闭。输入法不会自己创建带例子的模板。文件夹空着，就等于没有包。

这和设置里的「表情模式」不是同一个开关。表情模式只管安装包里自带的那一套：开了才出现，关了就没有，而且排在候选最前面。表情包不看这个开关。文件在，就出现。

表情、颜文字和符号都是文字，不是图片贴纸。显示成什么样，跟 Windows 的字体有关。

官方包有四个，都在仓库的 [`packs`](https://github.com/russianhub/pangyi/tree/main/packs) 目录里：

| 名字 | 里面是什么 | 条数 |
| --- | --- | ---: |
| `emoji-common` | 常用表情，拼音关键词，常用项带短俄语 | 70 |
| `kaomoji` | 颜文字 | 59 |
| `symbols-common` | 常用标点、数学符号、货币符号 | 66 |
| `symbols-russian` | «»、破折号、№、₽，以及俄语字母 | 75 |

拼音要打全。例如装上对应的包之后，`xiao` 对 😄，`lubu` 对 ₽，`eyuyo` 对 ё，`pozhehao` 对 —。打到一半不会出。包不参加首字母缩写。

官方包都没有写权重，所以排在这个拼音的内置精确第一名后面，不会盖住正常的词。同一个位置上，你在用户词库里加的词排在包的前面。包里的俄语只属于这一条候选，不会改掉词典里同一个词的俄语。

选中表情、颜文字或符号之后，不会写进自学习。删掉包之后，它们不会还留在候选里。

输入法只读已经在本机的文件，DLL 里没有下载代码。要从网上拿官方包，另外运行仓库里的 [scripts/pangyi-packs.ps1](https://github.com/russianhub/pangyi/blob/main/scripts/pangyi-packs.ps1)。不运行这个脚本，输入法就不会访问网络。脚本默认只从 `https://raw.githubusercontent.com/russianhub/pangyi/main/packs/` 下载，并核对 SHA256；对不上就不把文件放进文件夹。

在仓库根目录可以这样装其中一个：

```powershell
powershell -NoProfile -File .\scripts\pangyi-packs.ps1 -Install -Name emoji-common
```

四个都装、列出、删除的命令，以及自己写一个包怎么分给别人，见 [表情包和符号包](https://github.com/russianhub/pangyi/blob/main/docs/emoji-packs.md)。

官方包是旁译项目自己编写的 Unicode 字符和传统颜文字，按 CC BY-SA 4.0 分发。转给别人时保留文件头的说明，并以相同方式共享。

## 怎么使用

1. 下载并运行本页的 `pangyi-v4.18.0.exe`。安装包未签名。若出现 SmartScreen 提示，先确认来自本仓库的 Release，并核对本页文末的校验方法。
2. 首次安装后，按安装提示注销并重新登录（也可重启电脑）。从旧版升级时，保存工作，完全退出并重开使用旁译的应用（包括后台进程）。若仍像旧版，注销后重新登录。
3. 按 `Win + 空格` 选择「旁译」。
4. 加词或改俄语：打开 [用户词库](https://github.com/russianhub/pangyi/blob/main/docs/user-dictionary.md)，按里面的格式改 `user-dict.tsv` 或 `user-gloss.tsv`，保存后再打一遍那个拼音。
5. 要表情或符号：打开 [表情包和符号包](https://github.com/russianhub/pangyi/blob/main/docs/emoji-packs.md)，用 `pangyi-packs.ps1` 装一个官方包，或者把自己的 tsv 放进 `packs` 文件夹，然后再打对应的拼音。

## 需要重启吗？

| 场景 | 需要做什么 |
| --- | --- |
| 首次安装 | 按安装提示注销并重新登录，或重启电脑，完成系统输入法加载 |
| 从 v4.17.0 或更旧升级 | 保存工作，完全退出并重开使用旁译的应用（包括后台进程）；若仍未更新，注销后重新登录 |
| 改用户词库，或增删 `packs` 里的文件 | 不用重开应用，也不用重启电脑。保存后重新打这个拼音。大约每秒才看一次文件，刚保存有时要再打一次 |
| 日常开启/关闭英文模式、表情模式 | 无需重开应用或重启电脑，通常约 0.5 秒内生效。这是 v4.16.0 已有的行为，本版没有改这两个开关 |

热重载不能代替升级后的组件重载。应用要先加载 v4.18.0，用户词库和表情包才在那个进程里。

版本号只写在 [`ime/Cargo.toml`](https://github.com/russianhub/pangyi/blob/main/ime/Cargo.toml)。安装程序写进 `version.txt` 和「设置 → 应用」里的 `DisplayVersion`，资源里的 `FileVersion` / `ProductVersion`，都从 `CARGO_PKG_VERSION` 来。工作流不写死 `4.18.0`。

## 还没在真实 Windows 上验证

用户词库、表情包和符号包，目前只经过单元测试和持续集成。还没有在一台真实的 Windows 上，切到旁译，改这两个文件或装上包，然后在记事本里亲手打字确认。请不要把它们当成已经稳定的功能。和文档不一致时，请到 [Issues](https://github.com/russianhub/pangyi/issues) 反馈，并写上 Windows 版本、旁译版本和复现步骤。

另外，32 位 DLL 仍然没有在 32 位进程里加载过。CI 检查的是文件头和导入表（PE 机器类型 `0x014C`、导入 `msvcrt.dll`、不导入 `libunwind.dll`），不是在 32 位进程里 `LoadLibrary`。`windows-latest` 是 64 位系统。这一点从 v4.17.0 起就是这样。

下面这些需要有人在装了旁译的 Windows 上逐项看：

- [ ] 切换到旁译后，`%LOCALAPPDATA%\Pangyi\` 里出现 `user-dict.tsv` 和 `user-gloss.tsv` 的模板，例子不会变成候选。
- [ ] 在 `user-dict.tsv` 加一个自己的词，保存后重新打全拼，候选里能看到，旁边的俄语是自己写的。
- [ ] 在 `user-gloss.tsv` 给「的 / de」写一句自己的俄语，打 `de` 时「的」旁边是这句，不是原来的释义。
- [ ] 故意写一行坏的，出现 `user-dict-warnings.txt`；改好并重新打一个拼音后，这个文件被删掉。
- [ ] 用脚本安装 `emoji-common` 后打 `xiao`，😄 出现在这个拼音的内置精确第一候选后面，俄语是「улыбка」。
- [ ] 装上 `symbols-russian` 后打 `lubu` 能出 ₽，打 `eyuyo` 能出 ё；装上 `symbols-common` 后打 `pozhehao` 能出 —。
- [ ] 删掉对应的 tsv，重新打这个拼音，这条候选消失。改完保存，大约一秒后再打，能看到新内容。
- [ ] `user-gloss.tsv` 里给「的 / de」写的俄语仍然生效，包不会把它改掉。同一拼音下，用户词比包更靠前。
- [ ] 表情模式关掉之后，包里的候选还在。表情模式打开时，安装包自带的表情仍在最前；和包里重复的那条不出现两次。
- [ ] 选中一个表情或符号上屏后，`learned.txt` 里不出现它。
- [ ] 候选窗里的颜文字和表情没有变成方框（受字体影响）。
