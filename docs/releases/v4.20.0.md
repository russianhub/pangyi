# 旁译 v4.20.0｜设置窗口重做

这次把设置换成独立的 `pangyi-settings.exe`，并按 Windows 11 设置页的风格重做了界面。双击桌面上的「旁译」，或打开开始菜单里的「旁译」，就会进入这个窗口。输入法本体仍然完全离线，不联网，也不做遥测。

**[下载 Windows 安装包：pangyi-v4.20.0.exe](https://github.com/russianhub/pangyi/releases/download/v4.20.0/pangyi-v4.20.0.exe)**

安装包未签名。若出现 SmartScreen 提示，先确认文件来自本仓库的 Release，再按文末的方法核对 SHA256。

从 v4.19.0 升级时，请保存工作，完全退出并重开使用旁译的应用（包括后台进程）。若设置窗口仍是旧的一排按钮，注销后重新登录，或再运行一次本安装包。

## 新的设置窗口

来自 [PR #16](https://github.com/russianhub/pangyi/pull/16)、[PR #20](https://github.com/russianhub/pangyi/pull/20) 和 [PR #21](https://github.com/russianhub/pangyi/pull/21)。v4.19.0 里还是旧的设置面板。本版第一次把新窗口放进安装包。

- 左侧导航分成 6 项：输入、外观、翻译、词库、账号与更新、关于。
- 每页有标题和一句说明。设置按分组卡片排列，每一行左边是名称和简短说明，右边是控件。
- 开 / 关项用真正的开关（带「开」「关」文字）；多选项用分段控件；配色用圆点。
- 开关、分段控件和导航指示条都跟着你选的配色走（青、粉、橙、紫、绿），并支持浅色、深色和跟随系统。
- 「外观」页有候选窗预览，改排版、主题或配色会马上看到效果。正在打字的程序要等这次输入结束、下次激活旁译，候选窗才会换成新样子。
- 账号登录和检查更新仍由另外两个程序完成。这个设置窗口本身不联网。
- 设置项的键和原来一样，写在 `%LOCALAPPDATA%\Pangyi\settings.txt`。

许可证：[PR #15](https://github.com/russianhub/pangyi/pull/15)。设置程序自己的源码仍是 MIT。界面用 Slint 绘制，按免版税协议 LicenseRef-Slint-Royalty-free-2.0 使用，「关于」页有 “Made with Slint” 署名。输入法 DLL 不链接 Slint，仍按 MIT 分发。

## 怎么使用

1. 下载并运行本页的 `pangyi-v4.20.0.exe`。安装包未签名。若出现 SmartScreen 提示，先确认来自本仓库的 Release，并核对本页文末的校验方法。
2. 首次安装后，按安装提示注销并重新登录（也可重启电脑）。从旧版升级时，保存工作，完全退出并重开使用旁译的应用（包括后台进程）。若仍像旧版，注销后重新登录。
3. 按 `Win + 空格` 选择「旁译」。
4. 打开设置：双击桌面上的「旁译」，或打开开始菜单里的「旁译」。

## 需要重启吗？

| 场景 | 需要做什么 |
| --- | --- |
| 首次安装 | 按安装提示注销并重新登录，或重启电脑，完成系统输入法加载 |
| 从 v4.19.0 或更旧升级 | 保存工作，完全退出并重开使用旁译的应用（包括后台进程）；若设置窗口仍是旧界面，注销后重新登录，或再运行一次安装包 |
| 在新设置窗口里改候选个数、字号、排版、主题、配色、翻译模式 | 不用重开应用。正在打字的程序要等这次输入结束、下次激活旁译 |
| 日常开启/关闭英文模式、表情模式、中文标点 | 无需重开应用或重启电脑，英文模式和表情模式通常约 0.5 秒内生效 |

## 还没在真实 Windows 上验证

新的设置窗口在 Linux 上用 Xvfb 实际运行过 `pangyi-settings` 并截图，也通过了 Windows CI 的编译和单元测试。**没有在一台真实的 Windows 上运行过这个安装包，也没有在真实 Windows 上打开过新的设置窗口。** 请不要把「已经在 Windows 上用过」当成既成事实。若和文档不一致，请到 [Issues](https://github.com/russianhub/pangyi/issues) 反馈，并写上 Windows 版本、旁译版本和复现步骤。

32 位 DLL 仍然没有在 32 位进程里加载过。CI 检查的是文件头和导入表，不是在 32 位进程里 `LoadLibrary`。这一点从 v4.17.0 起就是这样。

下面这些需要有人在装了旁译的 Windows 上逐项看：

- [ ] 安装或升级后，双击桌面「旁译」打开的是新的设置窗口，而不是旧的一排按钮。
- [ ] 左侧导航可以在输入、外观、翻译、词库、账号与更新、关于之间切换。
- [ ] 改候选个数、字号、排版、主题、配色后，设置能保存；「外观」页的预览会马上变。
- [ ] 开关（中文标点、英文模式、表情模式、自动检查更新）可以打开和关闭，并写回设置。
- [ ] 浅色、深色和跟随系统都能正常显示，强调色会跟着所选配色走。
- [ ] 「打开账号窗口」「检查更新」能启动已经安装的对应程序；设置窗口自己不联网。
- [ ] 打字、候选窗和原来一样可用。

```powershell
Get-FileHash .\pangyi-v4.20.0.exe -Algorithm SHA256
```
