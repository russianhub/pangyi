# 账号窗口手工验收（Windows）

下面这些还没有在这台开发环境里用真实 Windows 桌面点过。装好带账号窗口的 `setup.exe` 之后，在一台 Windows 上逐项看。已发布的 v4.18.0 安装包里没有这个窗口，不要拿那个安装包做这份清单。

没有 Supabase 配置时，只做前半段。配好 `account.toml` 或编译期环境变量之后，再做后半段。不要把 `service_role` 写进配置。

## 不登录

- [ ] 安装后不打开账号窗口，在记事本里用旁译打 `pengyou`，候选和俄语还在。
- [ ] 用户词库、表情包不登录也能用。
- [ ] 用资源监视器或类似工具看宿主进程（记事本、浏览器）加载 `pangyi_ime.dll` 时没有 WinHTTP 连接。
- [ ] 设置里能看见「旁译账号 / 邮箱验证码登录」。点它会新开「旁译账号」窗口，宿主窗口没有弹出登录框，打字没有被卡住。
- [ ] 没有配置时，窗口写「登录不可用」，不能点发送，也不会变成「已登录」。
- [ ] 配置里如果放了 `service_role` 或 `sb_secret_`，窗口拒绝，并且不显示登录成功。
- [ ] `url` 写成 `http://` 时，窗口说明地址必须是 https，不发出请求。

## 登录和退出

- [ ] 输入邮箱，发送验证码。60 秒内按钮不可再次发送，并显示剩余秒数。
- [ ] 邮件里的数字可以登录。窗口变成「已登录」，并写明词库仍在本机。
- [ ] 关掉窗口再打开，仍然是已登录，而且访问令牌还没过期时不再联网。
- [ ] `%LOCALAPPDATA%\Pangyi\account.dat` 用记事本打开看不到刷新令牌或访问令牌的明文。`settings.txt` 里也没有令牌。
- [ ] 验证码填错，提示不正确或已过期，窗口仍是未登录。
- [ ] 发送后点「取消」，再把刚才的验证码填进去，不会登录成功。
- [ ] 发送后立刻再点一次，会提示正在处理或请等待，不会连发两封还显示两次成功。
- [ ] 拔掉网络后再发送，提示网络不可用，不显示已登录。
- [ ] 验证码超过 10 分钟再提交，提示过期。
- [ ] 退出登录后窗口回到未登录，`account.dat` 被删除。断网时退出，本机状态仍然清掉，并说明服务器会话可能要等过期。
- [ ] 再打开设置，打字、词库、表情包和退出前一样。
