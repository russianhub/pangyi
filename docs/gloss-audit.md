# 常用词俄语释义抽查

## English summary

Ranked the 5,000 most frequent simplified headwords in `ime/src/dict.tsv` by the baked-in jieba `freq` column (highest first; ties broken by code point). **4,981 / 5,000 (99.62%)** have a Cyrillic Russian gloss; **18** are empty on every reading. **1,362 / 4,981 (27.34%)** of the glossed words carry a stress mark (U+0301). In this slice, `manual`, `rw`, and `pint` glosses have **no** stress marks; pivot glosses usually do.

A uniform sample of 200 of those words (SHA-256, seed `20261103`; fingerprint `bcd91a51bf6eedcf3da20da51484c65401b71dc4e7dbe29b2b85f428c6b5c728`) was judged by one reader: **113 correct (56.5%)**, **56 acceptable (28.0%)**, **19 wrong sense (9.5%)**, **12 garbage or empty (6.0%)**. Twelve judgments are marked uncertain. The sample is not frequency-weighted, so it misses some of the worst high-frequency errors, in particular 的 (“bright / a white-blazed horse”) and 没 méi (“to die”).

Regenerate the counts with `python3 tools/audit_glosses.py`. The labels live in that script and are listed again below. Details of how the files are built: [data-pipeline.md](data-pipeline.md).

## 排名

单位是 `ime/src/dict.tsv` 里的简体词头（同一简体的多个读音算一个词）。词频取该词各行 `freq` 列的最大值。`ime/src/dict.rs` 把这一列说明为 jieba 词频；`tools/build_dict.py` 在写出 `data/zh-ru.tsv` 时还会对「帮、给、让、请、邦、浜」做 `FREQ_BOOST`。原始的 `jieba_dict.txt` 不在仓库里（`data/raw/` 除人工表外被 gitignore），所以这里直接用已经写进 `dict.tsv` 的数字，没有再乘一遍加权。

排序：词频从高到低，词频相同则按简体字符串的码位从小到大。取前 5,000。这样切出来的边界是确定的。

本次（`python3 tools/audit_glosses.py`）的结果：

- 词典共 454,385 个简体词头，其中 312,366 个词频大于 0。前 5,000 全部落在词频大于 0 的区间里。
- 第 1 名是「了」，词频 883,634。第 5,000 名是「誉为」，词频 1,557。下一名「溶液」是 1,556。
- 词频恰好为 1,557 的有 4 个词，全部在这 5,000 里：内力、大为、戒、誉为。

没有用 `ime/src/lm_uni.tsv` 做主排名。那份计数来自维基正文的最大匹配分词，里面有繁体词头和切碎的片段（例如「年月日」）。用它当「最常用的汉语词」会把另一套问题混进来。前 5,000 里有 4,984 个词也出现在 `lm_uni.tsv` 中。缺席的 16 个是：被切碎的长专名（中华人民共和国、全国人民代表大会及其常委会、中央军委、最高人民检察院、第二次世界大战）、人名（胡秉宸、李高成），以及銆、槸、鍦、笉、鏉、岃。长专名缺席是分词把它们切开了，不是这些词不常用。

全词典有 831 个词头的各行词频不一致（常见情况是一条有 jieba 词频、另一条 `nogloss` 行词频为 0）。排名用的是最大值。

## 覆盖率

「有俄语」指 `ru` 字段里至少有一个西里尔字母，并且不是 `en:` 开头的英文兜底。重音指 U+0301（词典里已经在用的组合尖音符，如 зака́нчивать）。候选窗按 `|` 把义项切开（见 `ime/src/dict.rs`）。

| 口径 | 数量 | 比例 |
| --- | ---: | ---: |
| 词头的 `ru` 非空 | 4,982 / 5,000 | 99.64% |
| 词头至少一条读音有西里尔俄语 | 4,981 / 5,000 | 99.62% |
| 所有读音的 `ru` 都为空 | 18 / 5,000 | 0.36% |
| 只有 `en:`、没有西里尔字母 | 0 / 5,000 | 0% |
| 至少一条读音带 U+0301 | 1,362 / 5,000 | 27.24% |
| 在「有俄语」的词里带 U+0301 | 1,362 / 4,981 | 27.34% |
| 这些词头所占的读音行有西里尔俄语 | 5,124 / 5,204 | 98.46% |
| 按 `\|` 切开的西里尔义项带 U+0301 | 3,000 / 11,611 | 25.84% |
| 其中两个元音以上的义项带 U+0301 | 2,998 / 10,212 | 29.36% |

非空但不是俄语的那 1 个词是第 3,909 名「黑鱼」，释义是拉丁学名 `Dalliidae | Ophiocephalus | Warpachowskii | argus`，没有西里尔字母。

18 个全空词头里，17 个是罕用字（銆、屽、鏄、槸、竴、屾、鍙、笉、鍚、鍒、鍏、鎴、鍑、湁、勫、湪、諲），来源多为 `nogloss` 或空的 `english` 行。唯一的普通词是第 2,164 名「是从」（`nogloss`，词频 4,054）。

重音几乎完全取决于来源。前 5,000 的读音行里：

| src | 有俄语的行 | 带 U+0301 |
| --- | ---: | ---: |
| manual | 1,977 | 0（0%） |
| rw | 769 | 0（0%） |
| pint | 57 | 0（0%） |
| （src 为空） | 1,201 | 387（32.2%） |
| pivot | 1,066 | 968（90.8%） |
| pivot-ext | 21 | 20（95.2%） |
| unihan | 26 | 25（96.2%） |

单音节虚词本来就常常不标重音。但 `manual` / `rw` / `pint` 连多音节词也不标，所以 27% 这个覆盖率主要是「枢轴译文带了重音，人工表和俄语维基这条链路没带」。

另外两个全表数字，方便后面看错误类型：

- 190 个多音词头里，63 个所有读音的俄语字符串完全相同；45 个有的读音有释义、有的为空。
- 148 个词的第一条 `|` 义项只是一个虚词（в、на、быть、не 等）。这是机械统计，用来对照「短语被拆碎」，不是人工判定。
- 200 个词的释义里含有分号。界面只按 `|` 分义项，分号两边会粘在同一条里。

## 抽样和判定

在前 5,000 个词里，取 SHA-256(`20261103` + TAB + 简体词) 十六进制最小的 200 个。比较的是十六进制字符串，不用 `random.sample`，换 Python 版本结果不变。抽样在这 5,000 个词上是均匀的：第 12 名和第 4,995 名权重相同，所以下面的比例不是「用户按一次键看到错译的概率」。

判定看的是常用读音、以及另一条同样常见的读音。生僻读音空着，但常用读音正确，仍算正确。界面把第一个 `|` 片段放在最前面，所以首义错、后面才对，算义项错误。

| 标签 | 含义 |
| --- | --- |
| 正确 | 常用读音的首义就是这个词的常用意思。缺重音、缺一个次要义，仍然算正确。 |
| 可接受 | 方向对。首义偏窄、短语被拆开但正确的词还在、或多了一条不严重的义项。 |
| 义项错误 | 给出的是另一个俄语词，对上了别的义项、别的读音，或英文枢轴的另一个意思。首义会把人带偏。 |
| 垃圾或空白 | 空字符串、词袋、残片、对不上的专名。看不出这个汉语词是什么意思。 |

标签写在 `tools/audit_glosses.py` 的 `JUDGMENTS` 里。脚本会核对这 200 个词和当次抽样是否一致，不一致就退出。

## 200 词的结果

| 判定 | 数量 | 比例 |
| --- | ---: | ---: |
| 正确 | 113 | 56.5% |
| 可接受 | 56 | 28.0% |
| 义项错误 | 19 | 9.5% |
| 垃圾或空白 | 12 | 6.0% |
| 正确 + 可接受 | 169 | 84.5% |
| 义项错误 + 垃圾或空白 | 31 | 15.5% |

12 条标了「不确定」，见下表。不确定集中在两处：近义词算不算正确（作者 / писатель，全国 / всенародный），以及拆碎的短语还能不能算可接受（当天、报考、推翻、统帅）。义项明显错的那一批（方面、事业、形式、石、事儿、承诺）不在不确定里，只有「人体」是在「义项错误」和「垃圾」之间犹豫。

这是一个人的判断。汉语释义我有把握；俄语近义词的语体差别我把握差一些。没有第二个人复核。

## 错误类型

下面先写抽样里反复出现的几类，再写抽样没抽到、但在频次表头部核对过的硬伤。头部这些不计入上表的 15.5%。

### 1. 多音字共用一条释义

俄语维基或枢轴按词给释义时，`build_dict.py` 在没有单独拼音的情况下会贴到这个词的每一个读音上。结果是冷僻义盖住常用义，或者两个读音变成同一句话。

抽样里：

- 降（第 1,446）：jiàng 和 xiáng 都是「падать; спускаться; спуститься | даровать; присуждать | уменьшить; понизить」。xiáng 的常用义是投降。
- 得（第 39）：行上的声调是 dé，释义却是「(суффикс наречия степени)」；děi 的释义是「получить; приобрести | …」，缺「必须」。结构助词和「得到」对调了。
- 句（第 1,371）：gōu 和 jù 都是「句子」。jù 是对的，gōu 不是。

头部另外核对过、不在这 200 词里：

- 的（第 9，`rw`）：de 和 dī 都是「яркий; чистый; отчетливый | белый; белого цвета | белый лоб лошадей; белолобая лошадь | центр мишени для стрельбы из лука」。这是「鲜明、箭靶」那条古义。结构助词「的」没有译文。这是整份表里影响最大的一条。
- 长（第 138，`rw`）：cháng 和 zhǎng 都是「длинный」。zhǎng（生长、首长）没有。
- 会（第 65）：huì 的人工表「уметь | мочь | собрание」是对的；kuài 被写成「собрание | встреча」。kuài 是会计，不是开会。
- 都（第 22）：dōu 的人工表「все | всё | уже」可用；dū 是「весь」。dū 的常用义是首都。
- 大（第 32）：dà 的人工表是对的；dài 也是「большой」。
- 给（第 37）：gěi 和 jǐ 都是「дать」。
- 和（第 4）：hé 的人工表「и | с | гармония」可用；hú、huó 是「и | да | с | сумма」。huó（和面）不是「和」。

前 5,000 里有 63 个多音词的各读音释义字符串完全相同。不全是错的（「这」zhè/zhèi 都是「этот」就说得通），但这一批值得整表扫一遍，而不是逐条碰运气。

### 2. 英文多义词被枢到了另一个义

`pivot` / `pivot-ext` 用 CC-CEDICT 的英文释义去对英俄词典，英文一旦多义，俄语就会落到另一个意思上。抽样里看得到的：

| 词 | 名次 | 现在的首义 | 枢轴踩中的英文 |
| --- | ---: | --- | --- |
| 方面 | 235 | уважение（尊敬） | respect（在……方面） |
| 事业 | 793 | ритуальные услуги（殡葬服务） | undertaking |
| 形式 | 514 | бланк（表格） | form |
| 石 | 715 | рок（摇滚），另有残片「горная )」 | rock |
| 事儿 | 4,270 | предприятие \| фирма | business |
| 承诺 | 4,266 | акцепт \| вексель（汇票） | acceptance / bill |
| 事项 | 3,300 | материя（物质） | matter |
| 头上 | 2,872 | 后面出现 накладные расходы | overhead（费用，不是头顶） |
| 均 | 348 | 释义里混着 униформа | uniform（均匀 / 制服） |
| 大概 | 2,603 | неровно（不平整） | rough |
| 识 zhì | 3,070 | грампластинка（唱片） | record |
| 明星 | 3,843 | Юпитер（木星） | 星名被安到了木星；звезда 在第二 |
| 榜 | 4,263 | весло（桨） | 文言「榜」有桨这个义，榜单没有 |
| 大国 | 4,545 | Пауэр | power，变成了专名式的音译 |
| 所以 | 207 | зато（反而） | 首义不是「所以」；потому 在第三 |
| 另一方面 | 2,570 | зато | 同上，с другой стороны 在后 |
| 曾 | 213 | как только | 曾经应是「曾经、一度」 |

同一类、但不在抽样里、在前 5,000 里核对过的：

- 没 méi（第 106，`pivot-ext`）：「сконча́ться | умере́ть」。méi 的常用义是否定。mò 是「коне́ц | край | дально」，「дально」还是残词。
- 落 luò（第 945，`pivot`）：「Сет」。英文 set 落到了专名。
- 单 dān（第 1,498，`pivot`）：「Билл」。英文 bill 落到了人名。
- 行 háng（第 320，`pivot-ext`）：首义「вероиспове́дание」（宗教信仰）。职业义在后面。

`build_dict.py` 自己的注释里已经记过单字枢轴会把「的」翻成 яркий、「开」翻成 кипеть。单字上的放宽后来收回了，但多字词和「有多个读音的单字」仍走枢轴，所以上面这些还在。

### 3. 俄语短语被拆成词袋

一条俄语被按空格切开，再拿 `|` 串起来。首义经常是一个介词。前 5,000 里有 148 个词的首义只是 в、на、быть 这类虚词。抽样里：

- 垃圾：具有（быть | в | вмещать | двусложным）、公元、更是、贯彻、好好、扩张（首义 желудка）、毫不（首义 волос）、统帅。
- 可接受（正确的词还在，但要自己拼）：实现、运用、满足、事务、当天、报考、推翻、林区、毕业生。

「двусложным」（双音节的）出现在「具有」里，和这个词没有关系。这类垃圾不是「译得生硬」，是切分把句子切坏了。

### 4. 空释义和挤进常用区的罕用字

抽样里的「湪」（第 4,838）两条都是 `nogloss`，释义为空。「鏉」（第 3,878，`pivot-ext`）是 sharp 的一堆义项（дие́з、е́дкий、о́стрый、остроу́мный），本义我不能确定，但这不是一条能用的词典释义。

全空的 18 个词头见上面的覆盖率一节。jieba 词频把这些字排进了前 5,000，和「全国」「市场」放在同一个常用区里。

### 5. 首义顺序和词典腔

有的词后面有正确义项，第一条却是错的或过窄的：战斗的首义是 драка（打架），бой 在第三；建立的首义是 назначить（任命）；一口只有 охотно；旁是 другой，不是旁边；亡的首义是逃跑和丢失，死亡不在。

残片和领域标记也会变成一条义项：石的「горная )」，肿瘤的「мед.」，句和景里的英文「Классификатор」，固然里的「корреспондирующим」，推翻里的「напр.」。全表还有一批括号不成对的释义（居民、老师、主张、口号等），多半是从词典体例里切出来的。

### 6. 重音

见覆盖率。人工表和 `rw` 在这 5,000 词里的重音率是 0。枢轴带重音的比例高，但枢轴也是错译最集中的来源。先改错译，再考虑给人工表补重音。

## 建议的修改顺序

按对使用者的影响排，不按实现难度排。

1. **先改「的」和「没」。** 「的」是第 9 名，结构助词没有任何俄语，两条读音都是「白额的马、箭靶」。「没 méi」是第 106 名，被写成「去世」。这两条都不在 200 词抽样里。做法可以沿用现成的人工表：`data/raw/manual-zh-ru.tsv` 已经能压过维基和枢轴（了、地、着就是这样救回来的）。
2. **多音字没有单独拼音时，不要把同一条俄语贴到每个读音。** 优先处理长、降、会 kuài、都 dū、大 dài、给 jǐ、和 hú/huó，以及所有「各读音字符串完全相同」的 63 个词。`build_dict.py` 里 ruwikt 在缺少 `pint` 时会走这条路径。
3. **给枢轴加一层英文多义词阻挡。** 至少挡 respect、undertaking、form、rock、business、bill、set、power、overhead、matter、uniform、record、sharp。对应方面、事业、形式、石、事儿、承诺、落、单、大国、头上、事项、均、识。错的首义即使后面跟着正确义项，也要删掉或放到后面，因为界面先显示第一条。
4. **不要把俄语短语按空格切成 `|` 义项。** 具有、实现、运用、当天、公元、扩张、统帅、好好、贯彻、更是都属于这一类。前 5,000 里首义为裸虚词的有 148 个，可以当修复名单的起点。
5. **把空释义的罕用字移出常用排序，并补上「是从」。** 銆、湪、鏉 这一串不该和普通词抢前 5,000 的位置。词频来自 jieba，要改的是「没有俄语的异体字还带着高词频」这件事，而不是再给它们配一条枢轴。
6. **重音另做一趟，不要和上面几件绑在一起。** `manual`、`rw`、`pint` 在这 5,000 词里重音为 0；pivot 约 91% 有重音。给人工表补 U+0301 对学习者有用，但挡不住「的」和「没」。
7. **清词典体例残留：** 不成对的括号、`напр.`、`мед.`、`будд.`、英文「Классификатор」。分号不会被界面切开，能改成 `|` 的再改。
8. **让 `ime/src/dict.tsv` 能从脚本再生。** 现在 `build_dict.py` 只写 `data/zh-ru.tsv`。前 5,000 的非 `nogloss` 读音里，有 5,094 条俄语与 `zh-ru.tsv` 相同，26 条不同，11 条只在 `dict.tsv`。`nogloss` 行没有生成脚本。见 [data-pipeline.md](data-pipeline.md)。
