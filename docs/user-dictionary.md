# 用户词库

旁译的大词库编在安装包里，不能直接改。你可以在自己电脑上加词，也可以改某个已有词的俄语。不用联网，不用账号。文件是普通的 UTF-8 文本，用记事本就能改。

这两份文件只留在你的电脑上，输入法不会上传。它们不属于词典数据的 CC BY-SA 分发；随软件发布的只有带注释的空模板。

## 文件放在哪

和自定义短语、自学习、设置同一个文件夹：

```text
%LOCALAPPDATA%\Pangyi\
```

在 Windows 上，这通常是：

```text
C:\Users\你的用户名\AppData\Local\Pangyi\
```

里面有：

| 文件 | 做什么 |
| --- | --- |
| `user-dict.tsv` | 添加词：词头、拼音、可选俄语、可选权重 |
| `user-gloss.tsv` | 改已有词的整条俄语 |
| `user-dict-warnings.txt` | 有读不进去的行时才出现。改完并重新打一个拼音后会更新；没有问题时会被删掉 |

第一次切换到旁译时，如果这两个 tsv 还不存在，输入法会写上带说明的模板。模板里的例子都用 `#` 注释掉了，不会突然多出候选。你删掉文件之后，下次开始输入时还会再生成一份空模板；已经写过的文件不会被盖掉。

### 打开这个文件夹

1. 按 `Win + R`。
2. 输入 `%LOCALAPPDATA%\Pangyi`，回车。
3. 用记事本打开 `user-dict.tsv` 或 `user-gloss.tsv`。
4. 保存时编码选 **UTF-8**。列与列之间用 **TAB**（键盘上的 Tab 键），不要用空格对齐。

改完保存，重新打这个拼音就会生效。输入法大约每秒才看一次文件有没有被改过，所以刚保存就立刻打，有时要再打一次。

## 添加词：`user-dict.tsv`

每一行 2 到 4 列，TAB 分开：

```text
词头	拼音	俄语	权重
```

俄语和权重都可以空着。空着俄语时，这一列留空即可（连续两个 TAB）。

```text
张三	zhangsan	Чжан Сань
旁译	pangyi	Панъи	100
内名	neiming
```

- **词头**要有汉字，最长 32 个字符。
- **拼音**写你要敲的字母。不标声调也可以。`ü` 用 `v`（女 = `nv`）。也可以写带声调的 `cháng`，或数字声调 `chang2`。读音不能空。
- **俄语**会显示在候选旁边。一般写俄语；写成别的文字也会原样显示。几个义项用 ` | ` 分开（和内置词一样，逗号、分号会被候选窗切开）。最长 400 个字符。
- **权重**是整数，范围 `-9999` 到 `9999`。怎么排见下一节。

多音字要分成两行，因为你敲的字母不一样：

```text
长氏	chang	длинный
长氏	zhang	расти | старший
```

`hǎo` 和 `hào` 敲出来都是 `hao`。同一个词头加同一个不带调的拼音只保留一行，文件里后写的那行生效。

拼音必须打全。`zhangsan` 要敲完 `zhangsan` 才会出现，打到 `zhang` 不会。用户词不参加首字母缩写，也不会被拿去拼更长的句子。

## 权重：排在第几

候选先按内置词库排序。然后才插入你的词。

| 权重 | 位置 |
| --- | --- |
| 不写、空着、`0`，或 `1`–`99` | 紧挨在这个拼音的**内置精确第一候选**后面。数字大的更靠前，但都不会超过那个第一名。 |
| `100` 或更大 | 可以排到那个第一名的**前面**。越大越靠前。 |
| 负数 | 排在所有内置精确候选的后面。越负越靠后。 |

「精确」是指你敲的拼音和这个词的读音完全一样，不是只打了前几个字母，也不是首字母缩写。

另外几条始终在用户词前面，权重也不能超过它们：

- 自定义短语（`phrases.txt`）
- 整句切出来的那一条

如果这个拼音本来没有内置的精确候选（比如一个人名），不写权重的用户词会排在短语和整句后面、其余候选前面。

已经是内置第一名的词，再在用户词库里写一遍且不把权重写成 `100` 以上，不会把它从第一名拉下来。想让某个已经有的词永远排第一，把权重写成 `100` 或更大。

自学习（你选过的词）不会把用户词抬到内置精确第一名前面。要它排在那个第一名前面，还是靠权重。

表情模式开着、并且拼音正好是表情关键词时，安装包里自带的那一套表情仍然排在最前面。那是候选窗另外加上的。另外可以下载表情包和符号包，放进 `packs` 文件夹就生效，不看表情模式这个开关。见 [表情包](emoji-packs.md)。

同一个权重时，文件里先写的更靠前。

## 改已有词的俄语：`user-gloss.tsv`

每一行 3 或 4 列：

```text
词头	拼音	俄语	说明
```

说明可以不写。写了也只是给你自己看，不进候选窗。这一列是为了能从 `data/gloss-overrides.tsv` 抄四列过来。

```text
的	de	（структурная частица）	结构助词
长	chang	длинный	长，不是生长
长	zhang	расти | старший	生长、年长
```

读音不能空。多音字一行一个读音：`长 / chang` 不会改到 `长 / zhang`。不标声调的一行（`chang`）会用在这个拼写的各个声调上；写了声调（`cháng` 或 `chang2`）就只改那个声调。

俄语是整条换掉，不会接在旧释义后面。

### 谁优先

同一个词、同一个读音，俄语按这个顺序取，上面的赢：

1. `user-gloss.tsv`
2. `user-dict.tsv` 里这一行写的俄语
3. 随软件发布的 `data/gloss-overrides.tsv`
4. 内置 `dict.tsv` 原来的俄语

同一文件里，同一个词头加同一个读音写了两行，后一行生效，并在警告文件里记一笔。

整句翻译只有上屏后的词头、没有读音。它跟着词典里词频最高的那条读音走。你为别的读音写的俄语，仍只出现在那个读音的候选里。一个内置词典里没有的词，如果你只给了一种俄语，整句翻译会用它；给了两种不同的俄语就不猜。

## 坏行

读不进去的行会跳过，其他行照常用。输入法不会因为一行写错就崩溃，也不会把整份文件丢掉。

下面这些是坏行：

- 列数不对（词库不是 2–4 列，释义不是 3–4 列）
- 词头是空的，或里面没有汉字
- 读音是空的，或里面有空格、无法识别的符号
- 权重不是整数，或超出 `-9999` 到 `9999`
- 俄语超过 400 个字符，词头超过 32 个字符

`#` 开头的整行和空行是注释。文件可以用 UTF-8 BOM，换行用 Windows 的 CRLF 或 LF 都可以。

警告写在 `user-dict-warnings.txt`，最多 32 条具体说明，再多会再加一行「还有更多问题没有列出」。

## 限制

| 限制 | 数值 |
| --- | --- |
| 每个文件最多读 | 256 KiB（262144 字节），多出来的不读 |
| 每个文件最多收下 | 5000 行数据（注释和空行不算） |
| 重新检查文件 | 大约每秒一次，在一次新的拼音开始时 |
| 拼音 | 要打全，不支持缩写，不参与更长句子的切分 |

这些上限是为了让一个意外的大文件不会拖住输入法启动，也不会去碰那份约 36MB 的内置 `dict.tsv`。

## 和短语文件的区别

`phrases.txt` 是「敲几个字母，直接出一整句」，而且永远排在最前。用户词库是正常的拼音词：读音要和你敲的拼音一致，排序跟内置词放在一起比。两套可以同时用。
